## 0. 先看目录关系

```text
仓库根
├── frontend/     Vue 3 工作台（浏览器）
├── backend/      FastAPI（唯一写库存入口在 inventory_service）
├── database/     空库建表 SQL + Mega Star 导入（已有库禁止再跑 DROP）
├── data/         Mega Star 原始 CSV
├── tools/        一次性导入 / MySQL 本机辅助脚本
├── docs/         开发、技术、本文件
├── backups/      迁移前 SQL 备份（不要当源码改）
├── docker-compose.yml
└── 使用说明文档.md
```

请求路径（简化）：

```text
View（.vue）
  → Controller（frontend/src/controllers）
  → Model / API 客户端（frontend/src/models，api 仅为再导出）
  → FastAPI Controller（backend/app/controllers）
  → Service
  → ORM 模型 / MySQL
```

`backend/app/api/v1/*.py` 与 `frontend/src/api/*.ts` 是 MVC 拆分后留下的**兼容再导出壳**，新逻辑不要往里加。

## 7. 改代码时先打开哪几个文件

| 你想改的事 | 先看 |
|---|---|
| 某个页面按钮 / 表格 | 对应 `views/*.vue` → `controllers/*.ts` → `models/*.ts` |
| 某个 HTTP 接口 | `backend/app/controllers/*.py` → `services/*.py` → `schemas/*.py` |
| 库存数量对不对 | **只改** `inventory_service.py`（不要在 controller / 助手里 `UPDATE`） |
| 助手答什么 | `assistant_service.py`、`agents/graph.py`、`agents/llm.py`、`agents/tools.py` |
| 菜单是否显示 | `frontend/src/config/pages.ts` + 后端角色 |
| 新表新字段 | 新写 Alembic `0006_*.py`（只加不删），同步 `db/models/` |
| 登录失败 / 权限 | `auth_service.py`、`dependencies.py`、`seed_roles.py` |
| 日志没有 request_id | `core/logging.py`、`core/middleware.py` |

## 8. 不要动的红线（和文件的关系）

| 红线 | 相关文件 |

| 助手不直接改库存 | `assistant_service.py`、`agents/tools.py` |
| 密钥不进 Git、不进文档 | `backend/.env`、`.admin-password` |
